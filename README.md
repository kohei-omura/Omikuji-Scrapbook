# 御神籤帖（ごしんせんちょう）

神社で引いたおみくじを写真で記録し、積み重ねた記録から**これからの指針**を受け取るためのPWAです。

記録はすべて端末の中（IndexedDB）にだけ保存されます。サーバーも外部データベースもAPIキーも使いません。

---

## できること

| 画面 | 内容 |
|---|---|
| 記録 | カメラ／アルバムから写真を取り込み、文字を読み取って下書き。日付・神社名・番号・運勢・総評・項目別・メモを記録 |
| みくじ帖 | 一覧表示。神社名・運勢・年月で絞り込み、新旧で並び替え。詳細から編集・削除 |
| 指針 | 最新のおみくじを「いまの御神託」として表示。運勢の流れ、くり返し現れる言葉、今日の一歩を提示 |
| 統計 | 運勢の分布（円）／月ごとの推移（折れ線）／神社ごとの回数（棒） |
| 設定 | 控えの書き出し・読み込み（写真を含む）、全削除、夜の帖（ダークモード） |

## 使っている技術

- HTML / CSS / JavaScript のみ（フレームワーク不使用・ビルド不要）
- 保存：IndexedDB（写真はBlobのまま保存）。設定のみ localStorage
- 写真の読み取り：Google Gemini API（`gemini-2.0-flash`／RESTを直接呼び出し）
  - **読み取りだけは通信とAPIキーが必要**です
  - APIキーは設定タブで登録し、この端末（localStorage）にだけ保存します
  - **控え（JSON）にAPIキーは含まれません**
  - オフライン時は読み取りボタンを無効にし、手入力に案内します
- オフライン対応：Service Worker（Cache First）


## 読み取りを使うまでの準備

1. Google AI Studio（aistudio.google.com/apikey）でAPIキーを作る
2. アプリの **設定 → 写真の読み取り（Gemini）** にキーを貼り、「保存する」
3. 記録タブで写真を選び、「写真から文字を読み取る」

## GitHub Pages で公開する手順

1. GitHubで新しいリポジトリを作る（例：`goshinsencho`）
2. この一式を**リポジトリ直下**に置く（`index.html` が最上位にくるようにする）
3. コミットして push する
4. リポジトリの **Settings → Pages** を開く
5. **Source** で `Deploy from a branch` を選ぶ
6. **Branch** に `main`、フォルダに `/ (root)` を選んで **Save**
7. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

> Service Worker と PWA は **https でのみ**動作します。GitHub Pages は https なのでそのまま使えます。

## ホーム画面に追加する

**iPhone / iPad（Safari）**
1. 上のURLをSafariで開く
2. 共有ボタン → 「ホーム画面に追加」
3. 追加すると、アドレスバーのないアプリとして開きます

**Android（Chrome）**
1. URLを開く
2. メニュー → 「アプリをインストール」または「ホーム画面に追加」

## 注意

- 記録はこの端末の中だけにあります。**機種変更やブラウザのデータ削除で消えます。**
  設定画面から定期的に控え（JSON）を書き出してください。
- 読み取りは誤りが出ます。保存前に必ず内容を確かめてください。
- Gemini APIの利用料・利用制限はGoogleの規定に従います。無料枠には回数制限があります。
- 写真はGoogleのサーバーへ送られて解析されます。記録そのものは端末内にとどまります。
- 運勢の順位は 大吉 > 中吉 > 小吉 > 吉 > 末吉 > 凶 > 大凶 として扱っています。
  神社によって並びが違う場合があります。
